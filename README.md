For the best experience in Google Colab:

1. Open the lab using the link above.
2. Select **Runtime → Change runtime type**.
3. Select a **GPU runtime (T4 or equivalent)** when available.
4. Run the notebook cells in order.

The core labs do not require access to IBM Spyre. Optional Spyre-specific sections are intended for learners with access to the appropriate Spyre environment.
